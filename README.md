# Hi, I'm Sevdegül 👋

I'm an Artificial Intelligence graduate from Johannes Kepler University Linz, based in Vienna. I'm interested in applied AI and technical consulting, especially projects where I can work with users to understand a problem, build a prototype, and measure how well it works.

## Selected projects

- **[Predicting Late Deliveries](https://github.com/sevdjewski/Predicting-Late-Deliveries)**  
  I analyzed 96,470 delivered e-commerce orders and compared logistic regression, gradient boosting, and a simple sorting rule. In the later evaluation period, the sorting rule identified 41.4% of late deliveries while flagging 10% of orders for review.

- **[LLM Evaluation Lab](https://github.com/sevdjewski/llm-evaluation-lab)**  
  I tested whether changing a first name in synthetic applicant profiles affected an LLM's recommendations. All 18 recommendations matched the reference decisions in the pilot, but four explanations attributed Python experience that the profiles did not mention.
